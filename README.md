# 응용데이터분석 (Applied Data Analysis)

**딥러닝 기반 데이터 분석** · 데이터사이언스융합학과 · 홍근선

> 모델은 정답을 맞히는 예측기가 아니라, **데이터의 구조를 드러내는 계측기다.**

이 저장소는 강의를 읽는 글로 다시 쓴 교재다. 여덟 개의 장은 그 계측기를 관측 공간에서
시작해 표현 공간 · 출력 공간 · 오류 공간 · Feature 공간 · 의존 구조로 차례로 옮겨 대 보고,
마지막에 그 결과들을 하나의 판단으로 통합하는 순서로 배열되어 있다.

## 읽는 방법

**온라인 교재** — <https://skku-ada.github.io/26h2/> (GitHub Pages 활성화 후 접속 가능)

검색 · 수식 렌더링 · 그림 확대 · 이전/다음 이동이 모두 동작한다. 이 방식을 권한다.

**내려받아 읽기**

```bash
git clone https://github.com/skku-ada/26h2.git
cd 26h2
python3 -m http.server 3000     # 브라우저에서 http://localhost:3000
```

GitHub 화면에서 md 파일을 직접 열어도 읽을 수 있지만, 수식(LaTeX)이 일부 깨져 보인다.
수식이 많은 장(3·4·5·7장)은 위 두 방법 중 하나로 읽는 편이 낫다.
